# CarBattleGame 🏎️

A mobile-friendly car battle game where you dodge enemy cars and survive as long as possible!

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. **Desktop Controls**: Use Arrow keys or WASD to move your car
4. **Mobile Controls**: Touch anywhere on the screen to move your car toward that position, or use the on-screen left/right buttons
5. Avoid red enemy cars while they drive down the road
6. Earn 10 points for each enemy car that you successfully dodge
7. You have 3 lives - the game ends when you run out of lives!

## Features

- ✅ Mobile-responsive design with touch controls
- ✅ Score tracking system
- ✅ Lives/health system
- ✅ Randomized enemy speeds for variety
- ✅ Animated road with moving lane markers
- ✅ Collision detection
- ✅ Game over screen with final score

## Technologies Used

- HTML5 Canvas for game rendering
- Vanilla JavaScript for game logic
- CSS3 for responsive styling
- Touch events for mobile support

## Play Online

Simply open `index.html` in any modern web browser. The game works on both desktop and mobile devices!
